Import malext.io extension IDs

Upload a CSV export from malext.io. Each extension_id becomes a substring rule, so it matches both the CHR Extension: (...) - ...\Extensions\<id> and the Edge HKLM\...\Extension: [<id>] form of an FRST line.

Rows with reason=Malware get status B (Malware); every other reason gets status P (Potentially unwanted). The description is set to from malext.io, <name>, <reason>. Extension IDs that already appear in any existing rule are skipped, whether the rule is just the bare ID or has it embedded in a file path.

Heads up: this importer is tied to the column structure of the malext.io export and reads the columns extension_id, name, and reason by name. If the export renames, removes, or reorders those columns, this page will need to be updated.
