api tokens

Personal tokens let an LLM client (Claude Desktop or Claude Code, through the FenrisHub MCP server) read uploads, verdicts, content search results, infection cases and fixlist snippets on your behalf. A token is read-only and sees exactly what you see when logged in.
Logs contain personal data of the people you help: Windows usernames, machine names, paths and IPs. Anything your LLM client reads is sent to its provider. Only pull what you need for the case at hand. Log text is written by the infected machine or anyone who uploads, so treat it as untrusted: do not let the model act on instructions found inside a log, and review every fixlist it drafts.

connect claude desktop or claude code
  1. Get the FenrisHub MCP server folder (server.py and requirements.txt) from the FenrisHub maintainer and put it somewhere permanent, for example C:\Users\YOUR_NAME\fenrishub_mcp\.
  2. Install Python 3.10 or newer, then create a separate environment for the server (PowerShell):
    python -m venv $HOME\.venvs\fenrishub-mcp & "$HOME\.venvs\fenrishub-mcp\Scripts\python.exe" -m pip install -r C:\Users\YOUR_NAME\fenrishub_mcp\requirements.txt
  3. Quit Claude Desktop completely: right-click its icon in the system tray and choose Quit. Closing the window is not enough, and Claude Desktop rewrites its config file while it runs.
  4. Open claude_desktop_config.json in a text editor:
    • Claude Desktop - Settings - Developer - Edit Config, if your version has that menu;
    • otherwise %APPDATA%\Claude\claude_desktop_config.json;
    • Microsoft Store version: a folder under %LOCALAPPDATA%\Claude-Data\.
  5. Paste this block on the line right after the opening { of the file, then replace YOUR_NAME and the paths with yours (keep the doubled backslashes):
    "mcpServers": { "fenrishub": { "command": "C:\\Users\\YOUR_NAME\\.venvs\\fenrishub-mcp\\Scripts\\python.exe", "args": ["C:\\Users\\YOUR_NAME\\fenrishub_mcp\\server.py"], "env": { "FENRISHUB_URL": "{{ api_base_url }}", "FENRISHUB_TOKEN": "{% if new_token_raw %}{{ new_token_raw }}{% else %}fh_YOUR_TOKEN{% endif %}" } } },
    If the file already has an "mcpServers" section, add only the "fenrishub" entry inside it, with a comma between entries. If the file was empty, it should read {, this block without its last comma, }.
  6. Start Claude Desktop again. In a new chat, fenrishub appears in the tools menu. When it asks to use a tool, allow it for the chat rather than "always allow".
Claude Code instead: after steps 1 and 2, one command registers the server:
claude mcp add fenrishub -e FENRISHUB_URL={{ api_base_url }} -e FENRISHUB_TOKEN={% if new_token_raw %}{{ new_token_raw }}{% else %}fh_YOUR_TOKEN{% endif %} -- "$HOME\.venvs\fenrishub-mcp\Scripts\python.exe" C:\Users\YOUR_NAME\fenrishub_mcp\server.py
If it does not show up: Claude Desktop writes mcp-server-fenrishub.log in a logs folder next to its config file. "No module named mcp" means command does not point to the environment's python.exe; "rejected the token" means the token is wrong, expired or revoked; "Could not reach FenrisHub" means the URL is wrong or the site is down.
